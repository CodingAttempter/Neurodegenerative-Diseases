# Neurodegenerative Diseases Project

An informational web project exploring various neurodegenerative conditions, their impact, and current research.

## 🚀 Live Demo
You can view the live website here: 
**[https://codingattempter.github.io/Neurodegenerative-Diseases/](https://codingattempter.github.io/Neurodegenerative-Diseases/)**

## 🛠️ Built With
* **HTML5** - Structure of the site
* **CSS3** - Styling and layout
* **GitHub Pages** - Hosting and deployment

## 📂 Project Structure
* `index.html` - The main entry point for the website.
* `css/` - Contains stylesheets (if applicable).
* `assets/` - Images and other media.
